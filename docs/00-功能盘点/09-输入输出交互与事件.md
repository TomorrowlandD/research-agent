# 输入输出、交互与事件

**核心结论。** 对话输入和审批已有可调用的 Python 接口，流式输出与工具进度主要面向终端。当前可以把一个异步审批决定送回仍在运行的 Agent；网页重连、跨进程续办和完整事件重放均需另行接入。

- **输入与审批。** CLI 把用户输入交给 `Agent.chat()`。普通工具审批通过 `await confirm_fn(提示文本)` 取得布尔值；计划审批另有回调，返回选择和反馈。CLI 在回调内同步读取 `input()`。普通审批回调的参数只有提示文本，工具调用 ID 保存在外层协议循环。[CLI 回调](../../agents/main.py#L147) · [审批入口](../../agents/agent.py#L2185)
- **输出与关联。** 文本片段经 `_emit_text()` 写入缓冲或终端；工具调用和结果则分别交给 UI 函数，渲染参数是名称与输入或结果。协议消息保留调用 ID，但终端渲染层没有向前端发布带 ID 的统一事件流。[文本出口](../../agents/agent.py#L609) · [工具展示](../../agents/ui.py#L81) · [结果回写](../../agents/agent.py#L2017)

| 场景 | 已确认的边界 |
| --- | --- |
| 页面刷新，后端仍在运行 | 离线样例用异步回调挂起审批，稍后返回决定，原任务能继续。网页要重新找到这次等待，还需要任务与审批请求的标识和查询入口。 |
| 等待期间进程重启 | 首轮等待时实测尚无会话快照。现有恢复入口读取已保存的消息与折叠记忆，未见待审批请求、执行位置或可恢复的等待记录。[保存与恢复](../../agents/agent.py#L928) |
| 完成后回看历史 | 离线样例从磁盘恢复出工具调用及配对结果，可据此展示本次调用。逐片段输出、审批提示出现的时间、进度变化等没有独立事件记录，无法据此完整重放。[快照字段](../../agents/agent.py#L996) |

**Web 接入评估。** 活动任务的审批可适配现有回调；可重连的进度与审批需要按会话、任务和工具调用关联的事件及状态。2026-11-22 在 WSL、Python 3.11.18 验证了进程内等待与完成后的历史恢复；浏览器重连和进程重启后的续办尚无端到端验证。[离线样例条件与结果](01-Agentic-Harness.md)
