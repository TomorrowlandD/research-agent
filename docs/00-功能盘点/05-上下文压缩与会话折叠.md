# 长程上下文压缩与会话折叠

**核心结论。** 主循环先对较长或较旧的工具结果做裁剪。完整折叠会把对话转成事件记忆、工作记忆和工具记忆，用这份摘要替换原消息历史。两条协议都有折叠路径；任务能否接续，取决于摘要是否保留了约束和下一步动作。[分层裁剪](../../agents/agent.py#L1130) · [双协议历史替换](../../agents/agent.py#L1035)

- **触发与保存。** 工具轮结束时，上次输入用量超过有效窗口的配置比例可触发自动折叠；用户可通过 `/compact`，模型也可通过 `compact_context` 主动触发。完整折叠受历史长度和次数上限约束。折叠记录写入项目会话目录，手动折叠还会立即保存可恢复的主会话快照。[阈值与入口](../../agents/agent.py#L1016) · [手动折叠](../../agents/agent.py#L915) · [折叠记录](../../agents/session.py#L31)
- **摘要质量边界。** 默认用一次辅助模型请求生成三类记忆；并行模式分别生成三份。默认模式遇到无效 JSON 会保留裁剪后的对话作为回退，但合法空对象 `{}` 会被规范化为空字段，仍可替换原历史。[生成与回退](../../agents/agent.py#L1070) · [字段解析](../../agents/session_memory.py#L190)

**离线验证。** WSL、Python 3.11.18，仓库折叠测试 12 项全部通过。另用固定摘要写明“只读”和目标文件，原 Agent 与从磁盘恢复的新 Agent 均从摘要读取约束和待办，通过真实文件工具完成下一次读取。相同历史分别输入无效 JSON 和 `{}`，前者在短样例中保住了目标路径，后者丢失了路径与约束。[测试入口](../../tests/test_folding_eval.py)

**Web 接入。** 可复用折叠记录和会话恢复入口。替换历史前应校验摘要是否含可用任务状态，并向上层区分正常折叠与降级。离线样例验证了接续机制，真实模型在多次折叠后的任务保真度仍待评测。
