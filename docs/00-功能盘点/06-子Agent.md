# 子 Agent

**核心结论。** 父 Agent 通过 `agent` 工具把一段任务说明交给同进程的新 Agent，等待其完成，再将子任务文本按原工具调用 ID 回写。子任务有自己的消息历史，与父任务共享工作目录；父任务可以取消正在等待的子任务。[委派与回传](../../agents/agent.py#L1523) · [取消入口](../../agents/agent.py#L460)

- **角色与上下文。** 子 Agent 接收角色提示和显式委派的任务说明，继承模型、权限模式和确认回调。内置 explore／plan 只配置读文件、列目录和搜索；也有自定义角色加载逻辑，但对模型公布的 `agent.type` 枚举只列三种内置类型。[角色配置](../../agents/subagent.py#L133) · [工具声明](../../agents/tools.py#L235)
- **结果与用量。** 创建时传入父任务剩余的费用和轮数上限。正常返回时，文本成为工具结果，主调用与辅助调用的用量归入父任务；这里没有把子任务已用轮数加回父轮数。子任务抛出的普通异常被转为工具错误文本，父循环可以继续。[结果结构](../../agents/agent.py#L564) · [用量归并](../../agents/agent.py#L1558)

**离线验证。** WSL、Python 3.11.18，模拟 OpenAI 回复、真实临时文件。从父 `chat()` 委派 explore 读取文件，验证了父对话中的标记未进入子消息、子任务读取结果回到父循环、用量计入父任务。注入子模型异常后父任务收到错误文本。在子任务已输出部分文本、仍等待响应时取消父任务，两者均停止；子任务没有独立会话快照，父快照中该工具结果保留了部分文本。[取消处理](../../agents/agent.py#L541) · [会话收尾](../../agents/agent.py#L556)

**Web 接入。** 委派和结果回传可复用。任务列表需要单独记录子任务标识及结束状态；仅从工具结果里的文字无法可靠区分正常完成和取消后的部分输出。
