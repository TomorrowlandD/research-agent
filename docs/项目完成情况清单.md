# ResearchAgent 项目完成情况清单

更新日期为 2026 年 11 月 21 日。用途是为后续产品开发和部署排期建立现状基线。

当前项目已具备本地 Agent 核心运行能力，处于底座功能已实现、部分场景已验证、产品交付能力待建设的阶段。主要使用方式为 CLI。产品面向的用户、业务闭环和部署平台尚待确定，因此当前适合按功能与验收项管理进度；总完成率暂缺计算依据。

本清单依据当前工作区代码、项目记录和本次会话中的检查结果。已有代码标为“已实现”，存在部分实现或已知缺口标为“部分完成”，当前工作区没有对应实现标为“待建设”。验证情况单独记录。“待建设”只描述本副本，不推断其他仓库或线上环境的状态。

服务化需要处理运行时与终端交互的衔接。当前 Agent 会直接输出终端文本，权限确认也依赖交互流程。接入 API 时需要明确消息与工具事件如何返回，以及审批如何暂停、恢复或拒绝任务。[运行时实现](../agents/agent.py)

会话文件位于用户主目录下的 .bear-code/sessions，折叠记录位于项目 .bear/sessions；长期记忆和 Skills 另有存储路径。容器部署时需要完整枚举这些目录并验证持久化。save_session 当前直接覆盖 JSON，get_latest_session_id 从全局会话列表选择最近记录。[会话实现](../agents/session.py) · [记忆实现](../agents/memory.py)
